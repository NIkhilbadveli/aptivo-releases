# Aptivo releases

Windows installers for [Aptivo](https://aptivo.live), published automatically by GitHub Actions.

- **Latest stable:** [AptivoSetup.exe](https://github.com/NIkhilbadveli/aptivo-releases/releases/latest/download/AptivoSetup.exe). The desktop app's auto-updater follows the release marked *Latest*.
- **Dev build:** the `dev` pre-release (`AptivoSetup-dev.exe`) is rebuilt on every change to the main branch. It is for testing only and is never offered by the website or the auto-updater.

Each installer ships with a `.sha256` file you can use to check the download.
